# 演出参数说明（v59）

所有常调参数都在 `src/tuning.ts`。改完保存，Studio 会自动刷新。每一项的含义和取值方向写在那一行的注释里，这里只按**成片时间**说明哪一段归哪组参数管。

- 单位：时间是秒，角度是弧度，位置和距离是 1920×1080 画面上的像素。
- 代码里的时间 T = 成片时间 + 1.167。只在 `direction.ts` 和静帧命令里会用到 T。
- 下面的“当前值”是交付时的值，其中标“用户”的是你定的。

## 最近常调的几组

### `CHU_BG`：三遍 CHU 的背景（v58）

背景是成员自己的 A 段（0:40–0:48）胶囊页底纹：HALO 是黄色光柱加斜条纹，POPY 是红白格子，MEW 是紫底加白色菱形和两侧灯架。画法和 A 段那一页是同一个函数，只是去掉了窗框和人物。底纹稍微虚化，人物头部后面再加一团成员色的光。

| 参数 | 当前值 | 作用 |
|---|---|---|
| `blur` | 6 | 底纹的虚化（px）。0 = 清晰；10 以上格子、条纹开始看不清 |
| `light` | 0.9 | 成员色的光的强度。0 = 不加 |
| `lightR` | 1300 | 光的半径（px），越大越铺满画面 |
| `lightX` / `lightY` | 0 / -120 | 光的中心相对人物脸的位置（右、下为正） |
| `still` | true | 底纹定格在这一幕开始的那一刻；false = 和 A 段一样在动 |
| `zoom` | 1 | 底纹放大倍数，越大格子、条纹越粗 |
| `pens` | true | 画面下方远处的观众荧光棒 |
| `sparkles` | true | 闪烁的小星星 |
| `veil` | 0 | 最后蒙一层白，越大越淡、人物越突出 |

A 段页面的颜色在 `direction.ts` 的 `tCapsules9(...)` 里按页指定（`['yellow', 'red', 'purple', 'red']`），两遍 A 段 MEW 都在第 3 页。

### `PEN_SWING`：0:18 的大荧光棒（v57）

| 参数 | 当前值 | 作用 |
|---|---|---|
| `startBeat` | 52 | **时机**：从第几拍开始挥（52 = フッフー 喊完的那个小节线），会自动加上 `CROWD_CALLS.beatLead`。+4 = 晚一小节 |
| `durBeats` | 1（v55 用户 1.5） | **速度**：从左挥到右用几拍，越小越快。只改变结束时间，开始时间不动 |
| `pivotX` / `pivotY` | 960 / 1600 | 握棒的手在画面下方的位置；`pivotY` 越大越像横扫，越小越像扇形 |
| `angle` | 0.75 | 往左、往右各挥多少 |
| `width` / `len` / `color` | 420 / 4000 / `#F2334F` | 粗细、长度、颜色 |
| `blur` / `bloom` | 0 / 0.35 | 虚化、自身光晕 |

署名段一直延续到荧光棒挥完，所以 `durBeats` 改小以后，署名段结尾的加速运镜（`CREDITS_OUT`）也会更早结束、更集中。

### `CREDITS_OUT`：0:18 前的加速运镜（v53，用户值）

`mode 'push'`、`lead 1.0`、`tau 0.2`、`zoom 70.8`、`rot 0.06`。从荧光棒开始挥之前 `lead` 秒起指数加速，到荧光棒挥完时达到 `zoom` 倍。`mode 'upRight'` 改为向右上拉，用 `upRight` 里的三个值。

### `CROWD_CALLS`：观众荧光棒（0:14–18、1:26–29、2:36–41）

这三段都不再显示 B小町！フッフー！ 的字（v59），只由荧光棒回应。1:26–29 只有一声 B小町！フッフー！，在第 256 拍的小节线上（成片 1:28.0，`direction.ts` 里 `tTour` 的 `callAt`）。

- 节奏：`beatLead 0.65`（用户）把挥动和抬起整体提前；`swayBeats 4` 是一个左右轮回的拍数；`swayShape 1`（用户）控制两端停留的长短。
- 幅度：`sway 0.38`、`creditsSway 0.38`（用户；0:14–18 和 1:26–29 共用）、`nearSway 0.2`。
- 抬起：`height 120`；`riseEnd 0.45` 和 `fallStart 0.6` 是一个轮回里抬到顶、开始放下的位置。
- 桥段：`bridgeScale 0.9`、`bridgeRaise 110`（用户，整体上移）。

### `PRE_KEYWORD`：0:32「1分1秒」、1:32「近い将来」（v59）

`size 228`（原 245）、`stepX 142`（原 130）、`stepY 248`（原 240）、`span 744`。字的边角碰到下一个字时，加大 `stepX` / `stepY` 或减小 `size`。

## 公式备忘

- サイリウム 切出的额外倍率是 `1 - endPull * exp((T - end) / accelerationSeconds)`。时间常数越小，前段变化越小，力量越集中在最后。
- `LYRIC_RASTER` 只影响字形边缘的精细度，不改变导出分辨率。`supersample` 改为 1 可以省渲染时间。

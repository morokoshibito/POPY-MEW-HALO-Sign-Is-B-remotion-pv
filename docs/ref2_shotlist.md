# 参考二（りりむ／葛葉／卯月コウ 版）逐段分镜与实测

> 注（v14，用户规定）：参考里看到的运动模糊/拖影一律不照搬。本工程任何时候都不加运动模糊、拖动残影；动感只靠镜头本身的速度和幅度。

时间都是本工程的画面时间 T（= 参考二时间 + 2.5 s）。
- 运镜数值由逐帧特征匹配测出，单位按 1920 宽换算。"画面内容向左" = 镜头向右移。
- 清晰度是拉普拉斯方差：图形段 300–2000，舞台段约 100，虚化特写 3–25。

## 转场手法（24 fps 逐帧）
1. 推近过曝：最后 5 帧加速推近，亮度升到接近白；切到下一镜时，新镜头先是缩放模糊，0.2 s 内落定。
2. 横甩：最后 4 帧加速横移加运动模糊，切到同方向运动的虚化画面。
3. 淡白：3 帧淡到白，叠一道黄色光斑，下一镜从白色中拉远出现。

## 第二轮研究（按用户的理解重看，24 fps / 10–12 fps）
- **运镜原则**：切入快、中段慢、切出快；转场和快切里大量用旋转镜头。
- **之前测量的误差**：A 段测到的"画面向上约 300 px/s"，其实是浮在人物上方、不断上升的星星；人物本身几乎不动。
- 片头 ア／ナ／タ：
  - 背景是成员的大特写，用该字的颜色做单色染色（线条仍可见）。
  - ア 一人；ナ 两人（新出现的人在上层，占背景大部分）；タ 三人。
  - 每个字的切入角度不同；巨大的单色话筒斜插。
  - タ 结尾，の 的灰色圆形从右下滚进来。
- アイドル：
  - 成员从画面底部弹上来（三遍各不相同），粉色同心圆从小圆开出。
  - 左「ドル」右「アイ」竖排落下。
  - 切出：画面旋转加速，同时大四角星爆开 → サイ 场景，橙色星和话筒摆入。
- B：
  - 黄色花形圆 → 灰白泼溅 → 橙色泼溅 → 三人错落、倾斜，头很大。
  - 霓虹线条爱心围在四周，左下的爱心在人物前面。
- CHU：C、H、U 依次弹出在脸的四周，背景有粉色波浪描边。
- 标题：
  - 粉色剪影淡出；三人依次叠入，每人入场前先有一道代表色剪影扫过。
  - 灰色气泡字逐个落下，再被黄色星一扫变成彩色。
- 署名：
  - 黄色圆环收口 → 粉红同心圆打开 → 三道聚光灯里站着三人，标题和名字逐行出现。
  - 荧光棒从画面底边升起：前排粗大，彼此交叠、倾斜，根部在画外，不悬空。
- Pre：
  - 歌词在竖向挂牌里（白底、粉色粗边、粉字），关键词（1分1秒）用巨大粉字斜着排在人物四周。
  - 叠层：下一位成员连同她的菱形框和字叠到前面；上一位被推远、缩小、虚化，留在一侧。
- 君も：
  - 中间一个圆形窗口（粉环），每人像钟摆一样转进、转出，摆动时虚化。
  - 君 在左上，も！在右下。
- お待ちどうさま：两段式。先是全景（三人很小，满屏大号爱心对话框、荧光棒），再快速推近，左右竖排大字。
- A 段：
  - 圆角窗口里的服装特写几乎不动；星星从下往上浮过人物。
  - 黄色光柱段配斜线和星；粉色段配灰色菱形和桁架；红色段配红白斜纹。
  - 胶囊：黑底、白色内边框，带一个小尾巴。
- ここに来たなら：
  - 三人小，在中间（剪影）；荧光棒分远中近三层，近的又粗又大、斜插在底部和两角；纸屑。
  - 镜头推近 1.34 倍，结尾红色荧光棒扫过变白。
- ちゃんと見えてる 君のサイリウム：
  - 像轮盘一样，每个短语换一个成员到前景（大、清晰、周围巨大白字）。
  - 另外两人在后方缩小、虚化，横向转换。サイリウム 时拉回三人全景。
- 副歌：
  - 全景里三人错落、远近不同，左右两人更近；最后一遍副歌带荷兰角，台阶是斜的。

  - 白色高亮底，暖色光晕从画面前面移过。
